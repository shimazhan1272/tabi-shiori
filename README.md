# 旅程作成ツール

ブラウザだけで使える旅のしおり作成ツールです。インストールや登録は不要で、`index.html` を開くだけで動きます。

## できること

- **旅程一覧**：旅程を20件まで保存し、切り替え・複製・削除ができます
- **基本情報**：タイトル、出発日・帰着日（〇泊〇日を自動計算）、目的地、参加者、メモ
- **旅程**：日ごとのタイムライン。時刻・カテゴリ・移動手段・場所・費用・URL・メモ
- **持ち物**：チェックリスト。プリセットから追加でき、プリセットは自分で編集できます
- **その他の費用**：保険・ビザ・通信・おみやげなど、日程に入らない費用
- **費用**：全体の合計、カテゴリ別・日別の集計、割り勘
- **通貨換算**：円と外貨の換算（レートは手入力）
- **名簿・緊急**：メンバーの連絡先、旅行保険、緊急連絡先
- **しおり**：冊子風の表示。予定のURLはQRコードになり、A4のPDFで保存できます
- **データ**：JSONファイルで保存・取り込み

## データの保存について

入力内容はブラウザのローカルストレージにだけ保存され、サーバーには送信されません。ブラウザのデータを消すと旅程も消えるので、必要に応じて「データ」タブからJSONファイルで控えを取ってください。

PDFの作成時のみ、作成用のライブラリ（html2canvas、jsPDF）を cdnjs から読み込みます。旅程の内容は送信されません。
